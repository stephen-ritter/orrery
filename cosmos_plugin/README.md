# cosmos_plugin — OpenC3 COSMOS CE plugin

Targets:

- `SAT_CHIEF` — what the satellite knows about itself. Telemetry arrives over the
  `gs_tcp` beacon port; commands leave over the uplink port (one interface, two
  streams); cmd/tlm are AUTO-GENERATED by `codegen/eds2cosmos` from the pinned
  cFS checkout's EDS into `targets/SAT_CHIEF/cmd_tlm/`. Hand-editing the generated
  files is forbidden; bump cFS, re-run the generator, re-load the plugin.
  The beacon carries the whole control story: `BSK_LINK_SENSOR_FRAME_TLM`
  (what the satellite senses), `BSK_LINK_TORQUE_COMMAND_TLM` (what `fcs` commands)
  and `FCS_HK_TLM` (mode/gains/counters); ground commands are `FCS_CMD`
  (NOOP/ENABLE/DISABLE) and `FCS_SET_GAIN` (live gain upload). Truth stays off
  this target by construction — `TruthState` has no TopicId, so it cannot exist
  inside cFS.
- `BSK_TRUTH` — sim ground truth, fed directly from Basilisk over the truth
  channel. Generated by `codegen/eds2cosmos` from the mission EDS tree
  (`BSK_LINK/TruthState` is in the link package already).

Interface (`plugin.txt`):

- `GS_TCP_INT` — `openc3/interfaces/tcpip_client_interface.py` to gs_tcp with
  **asymmetric ports**: `host.docker.internal` write_port **5051** (uplink,
  commands only) / read_port **5050** (beacon, telemetry only), framed by the
  stock `length_protocol.py` straight off the CCSDS length field
  (bit 32, 16 bits BE, total = field + 7). No custom protocol code.
  Gotcha (CE v6 Python build): the constructor signature is
  `(hostname, write_port, read_port, write_timeout, read_timeout, ...)`, NOT the
  Ruby `host port cmd_port tlm_port` order — an extra positional silently lands
  on `protocol_type` and the interface crash-loops with
  `No module named 'openc3.interfaces.protocols.1_0_'`.

Install / refresh (uses the COSMOS CE checkout at `~/Projects/cosmos`):

```bash
scripts/cosmos_stack.sh        # stack up + setpassword + build & load gem
```

The plugin gem ships `targets/SAT_CHIEF/**`, which CE v6 auto-registers; there
are intentionally no `FILE` keywords in `plugin.txt`.
